## 4. The Odds API database

**What it is:** data/oddsapi (compact backfill files plus daily raw pulls), built into data/oddsapi/odds.sqlite by sharp/odds_db.py.
- **Research only:** backtests, replays, the validation audit.
- **Not the board:** live prices and closes come from the tracker's own price logs (signals.yml does not even check this folder out).

**Is it pulling?** Yes. oddsapi.yml runs daily at 4:23 AM ET and has succeeded every day; 2.94M credits are left this month.

**What was wrong and is fixed (commits 606d8081, 08902b0b):**
1. **2026 NFL games were filed as sport "nfl_lines_at".** The research file of lines at fixed minutes before kickoff was read first and
   named the games, so all 272 2026 NFL games were missing from sport = nfl and got no results. odds_db.py now files any <sport>_lines_at
   plan under its sport (boxing too).
2. **Final scores had not been refreshed since 11/6.** Nothing ran sharp/hist_schedule.py. The daily job now refreshes the last 4 days,
   and the 11/5-11/23 gap was backfilled.
3. **Weekday CFB (Tue-Fri) was never pulled.** It now is daily, and 8/28-11/21 was backfilled (98 snapshots, 2,940 credits).
4. **Soccer was last pulled 5/29.** EPL is now pulled daily; the 2026-27 season (8/15 on) backfill is running.
